# 🔍 Visualizador de Perfil do GitHub

O **Visualizador de Perfil do GitHub** é uma aplicação web funcional que permite aos usuários buscar perfis do GitHub pelo nome de usuário. O sistema consome a API oficial do GitHub para exibir informações do perfil e uma lista dos repositórios mais recentes.

## 🚀 Funcionalidades
- [x] Busca de perfis do GitHub por nome de usuário.
- [x] Exibição de informações do perfil (Avatar, Nome, Bio, etc).
- [x] Listagem dos 10 repositórios mais recentes, ordenados por data de criação.
- [x] Design Responsivo (Adaptado para computador e celular).
- [x] Animações suaves para uma melhor experiência do usuário.

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Para a estrutura semântica da página.
- **CSS3**: Para o design, animações e responsividade.
- **JavaScript (Modules)**: Para a lógica de busca e integração com a API.
- **API do GitHub**: Fonte de dados para perfis e repositórios.
- **DevIcons**: Biblioteca de ícones para o visual.

## 📁 Estrutura do Projeto
- `index.html`: Página principal da aplicação.
- `src/css/`: Pasta com os arquivos de estilos (reset, animações, layout e responsividade).
- `src/js/`: Pasta com os scripts de lógica, consulta à API e renderização na tela.

## ⚙️ Como executar o projeto
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no seu navegador de preferência.
3. Digite um nome de usuário do GitHub no campo de busca e clique em "Buscar".

## 📝 Aprendizados
Como iniciante na programação, este projeto me ajudou a entender melhor:
- Como consumir dados de uma **API externa** usando `fetch`.
- Como organizar o código JavaScript em **Módulos**.
- A importância de um **Design Responsivo** e de animações para a experiência do usuário.
